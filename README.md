# My Pet

My Pet is a simple, friendly care hub for pet parents. Keep medication routines, vaccination dates, and grooming visits together for each pet.

## Run locally

Open `index.html` in a modern browser. No build step or package installation is required. Pet profiles and care records are stored in that browser's local storage.

## What you can do

- Create profiles for multiple pets and switch between them.
- Track medication schedules and mark daily doses as given.
- Save vaccination and grooming records with their next due dates.
- Review today's care and upcoming reminders from the overview.

The app's care workflows are informed by common pet-care app patterns such as dose completion history, vaccination reminders, and an at-a-glance care calendar. It is an independent implementation and is not veterinary advice.

## Product references

- [11pets](https://play.google.com/store/apps/details?id=com.m11pets.elevenpets&hl=en-US) highlights medication reminders, appointment scheduling, shareable health records, and vaccination-document storage.
- [PetDesk medication tracking](https://petdesk.com/blog/using-petdesk-to-remember-pet-medications) describes medication regimens, dose schedules and completion history, calendar sync, and refill reminders.

My Pet focuses these patterns on the initial scope: medication routines, vaccination records, and grooming reminders.
